# 🌐 SameepNav - Netscape Antigravity Navigator 🌐

An interactive retro Netscape Navigator 4.0 simulator featuring an **Ask Jeeves 2D Physics Antigravity Bill Calculator**, interactive window shattering, and chaotic UI experiments.

## 🌟 Included Web Apps

### 1. 🌌 Netscape Navigator & Ask Jeeves (`index.html`)
* **Authentic 90s Netscape Chrome:** Title bar, menu bar, navigation toolbar, animated comet throbber (`N`), and status bar.
* **Matter.js 2D Rigid Body Physics:** When the user enters their monthly expenditures and clicks "Ask", the financial weight shatters the entire interface into floating, bouncing 2D objects.
* **Zero-G Cyclic Modes:** Cycle between **1.0G (Downward)**, **0.0G (Zero-G Drift)**, and **-1.0G (Inverted Sky Gravity)**.
* **Throwable UI:** Click and drag any element to toss it across the screen with retro 8-bit collision sound effects.
* **Netscape Security Alert Trap:** A broken modal where the `OK` button wiggles away and locks incrementally with every click (`OK (LOCKED: X)`).

### 2. 🔀 Smooth Chaos Form (`chaos-form.html`)
* Deceptively modern account setup form with FLIP-animated field shuffling on `blur`, `Space`, or 7s idle.

### 3. 🔥 Enterprise Portal 2000™ (`ragebait.html`)
* Unhinged ragebait registration form with a displaced trailing cursor (+26px), vowel penalty, and an impossible 25-digit-sum password game.

## 🛠️ Deploying to GitHub Pages

1. Go to repository **Settings** on GitHub: `https://github.com/samxcore/sameepnav/settings/pages`
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. Within 1-2 minutes, your website will be live at `https://samxcore.github.io/sameepnav/`!
